# PeleMele · 设计规范

## 0. 名字与气质

**PeleMele** 来自法语 *pêle-mêle*：混在一起、热热闹闹的一堆。
它不是“又一个效率工具”，而是一家人共同拼贴的时间海报。
Slogan：**把一家人的时间，拼成一张温暖的海报。**

关键词：暖、圆、 boldly warm、贴纸感、手作感、留白、不幼稚。
避免：蓝灰企业风、细小网格、密集文字、拟物皮革、廉价渐变。

---

## 1. 反表格的四个视图

### 今天 · 「今日海报」
- 顶部问候 + 日期大字 + 家庭成员头像堆叠。
- 下一个“值得期待”的事件做成大幅海报：渐变纸面、类型印章、倒计时。
- 今天的时间线：一条手绘点线，卡片左右轻微错落，时间做成贴纸。
- 本周 7 天小拼贴：圆角票根，事件用色点，今天有手绘圈。
- 右下“合拍时刻”：下一段父母共同空闲，直接 CTA 安排。

### 节奏 · 「一日故事」
- 顶部 7 个圆形日期节点连成一条起伏的波浪线（SVG path），今天填色，活动日带小点。
- 下方选中日的“故事线”：大日期 + 时间渐变背景 + 纵向虚线；事件卡交替左右出现，像杂志跨页。
- 空白天显示温和的插画式提示，而不是空白表格。

### 花园 · 「周纸带」
- 每个月按周排成 4–6 条纸带；每条纸带是一条大圆角卡，7 个日期泡泡用虚线连接。
- 事件不是格子里的文字，而是落在日期下方的彩色小贴纸（桌面显示标题，移动端显示圆点）。
- 点击日期 → 底部抽屉列出当天全部活动，可直接新增。
- 下方“本月高光”：旅行/生日的横滑海报。

### 合拍 · 「重叠的形状」
- 标题旁是两个半透明圆叠出的装饰图形（代表两个人）。
- 成员选择器：大 avatar chips。
- 未来 7 天，每天一条时间缎带：08:00–22:00，忙碌是斜纹软块，共同空闲是渐变发光胶囊，并标出时长。
- 顶部“最佳合拍”3 张提案卡；一键把空档变成活动。
- Google 未连接时：一条清楚的连接提示 + “示例忙碌”开关（明确标注演示）。

## 2. 视觉 token

### 布局
- 移动端：16px 页边距，底部浮动 Dock（高 64 + 安全区），内容底部留 110px。
- 桌面：最大宽 1180px，顶部导航；两栏 7/5 或 8/4。
- 圆角：卡片 28px，按钮 999px，贴纸 14px，输入 18px。
- 间距：4 的倍数；主要块间 20–28px。

### 字体
- 拉丁/数字：Fredoka Variable（600/700），用于 logo、日期大数字、统计。
- 中文：系统圆润字体优先 `"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei"`，标题 800。
- 标题字距 -0.02em；正文行高 1.6。

### 层次
- 背景 = 纸（带 1.5% 噪点 + 柔光斑）。
- 纸面卡 = surface + 1px 半透明墨色描边 + 大圆角 + 柔和投影 + 底部 3px 的“硬阴影”贴纸感。
- 主按钮 = 主色 → 副色渐变，深色字；hover 上浮 2px。
- 类型色只用于小面积（贴纸、圆点、渐变的一角），大面积保持暖纸色。

### 动效
- 入场：opacity + translateY(10px) + scale(.985)，220ms spring 近似。
- 卡片 stagger 30ms。
- Dock 激活：胶囊背景滑动 + 图标轻微弹跳。
- 保存：按钮周围 6–8 个纸屑粒子（可关闭）。
- 全部动效在 `prefers-reduced-motion: reduce` 下退化为无动画。

### 可访问性
- 正文对比度 ≥ 4.5:1，大字 ≥ 3:1；主色不直接承载小号正文。
- 所有交互元素有 `:focus-visible` 2px 环；图标按钮有 aria-label。
- 弹层：`role=dialog`、Esc 关闭、焦点进入/返回、背景滚动锁定。
- 颜色不是唯一的信息渠道：事件类型同时有 emoji + 文本。

## 3. 皮肤系统

CSS 变量（挂在 `[data-skin]`）：

```
--bg          页面底色
--bg-2        次级底色
--surface     纸面
--surface-2   次级纸面
--ink         主文字
--ink-soft    次级文字
--line        描边
--primary     主色
--primary-2   副色
--accent      点缀
--pop         高亮（生日/旅行）
--mint        辅助
--shadow      阴影颜色
--glow-a/b    背景光晕
```

预设：蜜桃汽水、青柠野餐、泡泡糖、海盐日落、可可夜。
自定义：用户选 `bg / primary / accent`，其余用 `color-mix()` 派生（同时给旧 WebView 回退值）。
每个皮肤的 `theme-color` 同步到 meta，影响 iOS 状态栏与 Android 地址栏。

## 4. 组件清单

- `BrandMark`：三个重叠 blob（代表家人）+ 小笑脸，SVG，可单色。
- `Avatar` / `AvatarStack`：圆形、彩色底、emoji + 名字首字母；支持尺寸 sm/md/lg。
- `TopBar`：logo、日期、头像、设置。
- `Dock`：今天 / 节奏 / 花园 / 合拍；移动端浮动，桌面端内联。
- `DayOrb`：周/月选择器的日期泡泡，含事件圆点、今天态、选中态。
- `EventCard`：类型贴纸、标题、时间、地点、参与者；三种密度（poster / card / mini）。
- `Timeline`：手绘点线 + 交错卡片，支持“现在”线。
- `WeekWave`：SVG 波浪连接 7 个 DayOrb。
- `MonthBand`：一周纸带。
- `AvailabilityRibbon`：时间缎带（busy 斜纹 + free 胶囊）。
- `Sheet`：底部抽屉/居中弹窗，支持键盘与焦点管理。
- `EventForm`：类型 Emoji、标题、日期、时间、参与者、地点、备注、冲突提示。
- `ThemePicker`：皮肤卡 + 自定义三色。
- `Toast`：底部浮动提示。
- `EmptyState`：手绘星星 + 温和文案。

## 5. 文案语气

短、暖、具体；像家人说话，不像系统通知。
- “周五好，小满一家”
- “下一件值得期待的事”
- “这周六，你们有 3.5 小时合拍”
- “和『豆豆游泳课』撞了 30 分钟，要换个时间吗？”
- 空状态：“今天留白，正好去公园走走。”

---

## 6. 数据与隐私

- 默认 localStorage，无账号；可导出 `pelemele.json`。
- Google 只取 free/busy，不存标题；token 只在 sessionStorage。
- 家庭同步使用自部署 Node 服务 + 家庭码；Google token 永不同步。
- 设置里用一句话说清：“你的日程只属于你家。”
